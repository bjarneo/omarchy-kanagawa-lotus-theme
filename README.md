# Kanagawa Lotus

A light Kanagawa Lotus theme for [Omarchy Quattro](https://github.com/omacom/omarchy).

![Kanagawa Lotus preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/bjarneo/omarchy-kanagawa-lotus-theme
```

## Optional Neovim Theme

`neovim.lua` configures Kanagawa Lotus for manual use. Omarchy does not install Lua from third-party themes.

See [Kanagawa Dragon](https://github.com/bjarneo/omarchy-kanagawa-dragon-theme) for the dark counterpart.
